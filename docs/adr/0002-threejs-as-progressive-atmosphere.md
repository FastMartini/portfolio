# Keep Three.js in a progressive atmospheric layer

The portfolio will use Three.js for dimensional terrain, lighting, fog, camera drift, and other atmospheric effects behind the Mountain Journey. A synchronized HTML/SVG layer will own the trail, contour accents, Waypoint markers, navigation, project information, and actions. The scene is art-directed by scroll and offers no direct camera rotation, dragging, or free-orbit controls. Capable mobile devices may receive a simplified Three.js scene, while reduced-motion preferences, unavailable WebGL, or poor runtime performance trigger a static HTML/SVG atmosphere with identical content. This boundary preserves the distinctive three-dimensional experience without making core content dependent on WebGL, protecting accessibility, search visibility, and mobile performance.
